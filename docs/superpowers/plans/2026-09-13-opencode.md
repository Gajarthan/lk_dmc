# OpenCode migration implementation plan

**Goal:** Replace the external hub dependency with OpenCode analysis and GitHub exports.

**Architecture:** Keep collection and extraction unchanged. Add opencode.py for the
HTTP contract and analysis.py for persisted per-document results. publishing.py
becomes a neutral JSONL exporter. Wire the stages through CLI and GitHub Actions.

**Stack:** Python 3.11+, requests, existing atomic storage helpers, pytest, uv, Ruff.
